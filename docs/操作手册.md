## 一、开始使用

### 登录

打开网址后是全屏登录页。

- **已有账号**：填用户名密码 →「登录」。用户名**不区分大小写**（`MartinXie` 和 `martinxie` 是同一个账号）
- **新用户**：点「注册」标签 → 用户名 3–20 位（字母/数字/下划线）+ 密码至少 6 位

登录状态保持 **7 天**，过期需重新登录。改密码会让所有设备上的登录态立即失效。

### 界面语言

**纯中文单语界面**，无语言切换。所有对外产出也都是中文 —— 面向国内自媒体平台。

### 新用户会拿到什么

| 项目 | 是否预置 |
|---|---|
| 17 条系统提示词 | ✅ **注册时直接从管理员当前的提示词配置拷一份** |
| 大模型配置 | ✅ 预置服务端托管密钥的内置模型（密钥不下发到浏览器） |
| 资产 / 工作区 | ❌ 空 |

> 提示词是在**注册那一刻**在服务端拷好的，不需要等页面加载。管理员后来改了自己的提示词，不会回溯影响已注册的用户 —— 每个人拿到的都是注册时的快照，之后各自独立。

## 二、推荐工作流

不必按顺序走完，但这条链路上前一步的产出会自动喂给后一步。

```
选品 → 商品情报抓取 → 图文生成 → 视频生成 → 自媒体资产
         ↑
     热点发现（找选题）
```

### 路径 A · 从商品出发（有货源）

1. **选品** —— 输入品类词（如 `智能猫砂盆`），设好价格带和好评率，「开始选品分析」。看 11 列表格里的「差评集中在」——那是你的机会点
2. **商品情报抓取** —— 把商品详情页链接粘进来，「抓取商品信息」；不确定用什么链接就先点页面上的**内置样例**（8 个实测可抓的当当商品页）。抓完检查下方**核对区**，抓错的地方直接改（改动会被后面的生成采纳）
3. **图文生成** —— 选平台（小红书 / 微信公众号 / 今日头条 / 知乎 / 微博），点「①+② 一步到位」出文案 + 3 张配图
4. **视频生成** —— 从「已生成文章」下拉选刚做的那篇 → 选平台（抖音 / 快手 / 视频号 / 小红书 / B站）→ 生成脚本 → 检查/编辑脚本 → 「生成完整成片」
5. **自媒体资产** —— 所有产出都在这里，可搜索、可下载

### 路径 B · 从热点出发（找选题）

1. **热点发现** —— 两个源：「🔍 全网搜索（Bing/百度）」和「📰 资讯聚合（AI 情报）」。点内置关键词或自己输中文
2. 看到合适的热点卡，直接点卡上的「生成图文」或「生成视频脚本」——会带着热点上下文跳到对应页
3. 之后同路径 A 的 3–5 步

### 路径 C · 只要单个产出

四个工具页可以独立用，不需要前置：

- **自由问答** —— 通用 AI 问答，可传参考图、可开联网搜索
- **文案创作** —— 任何中文文案。选类型（软文 / 视频脚本 / 短平快帖子 / 私域推文）+ 投放位（10 个国内平台，含淘宝·天猫详情页）
- **图片创作** —— 商用图。可上传参考图
- **视频创作** —— 不依赖文章的视频生成

## 三、各页面操作要点

### 选品

**先设筛选再搜**：价格带是**自由文本框**（留空 = 不限，可填「200-500」这类国内客单价区间），好评率默认 85%。这两个值决定候选池，搜完再改要重跑。

**怎么读结果**：
- 「近一个月销量」是真实销量信号，比评分更能说明需求
- **「差评集中在」是最有价值的一列** —— 现有产品没解决的问题就是你的差异化空间
- 标 `N/A` 的字段是**真的抓不到**，不是漏了。系统刻意不让模型编数字

**复制表格**：点「复制表格」出来是**带边框的表格**，直接粘进 Excel / Word / 飞书都保留格式。

### 热点发现

**两个源不是二选一，是场景不同**：
- 🔍 全网搜索（Bing / 百度）—— 拿到带真实链接的搜索结果，适合核实与追溯来源
- 📰 资讯聚合（AI 情报）—— 由模型汇总近期动态，适合快速铺选题

切换源时下面的 10 个内置关键词也会换一套，因为两边的高效关键词不一样。

### 商品情报抓取

**支持**：服务端渲染的商品详情页 —— 当当、有赞 / 微盟搭的独立商城，以及任何带标准 `ld+json` 商品结构的站点。

**不确定用什么链接就先点内置样例。** 页面上 8 个当当商品页是实测可抓的，用来先熟悉输出长什么样。

**抓完一定要看核对区**。这是个可编辑的富文本框，抓取难免有误差，你在这里改的内容会被后续所有生成读到 —— 比重新抓一次更快。

**遇到抓取失败**：如果提示碰到了反爬拦截，按页面给的三条建议来：① 稍后重试 ② 换成规范的商品详情页链接 ③ 手工把商品信息粘进核对区。第三条最可靠。

> 大平台（淘宝 / 京东 / 拼多多 / 抖音小店）的商品页由前端 JS 动态渲染并带强反爬，服务器直抓多半只能拿到站级页面。碰上这种情况页面会明确告诉你「没拿到真实商品名和价格」，而不是把站点名当商品名往下传 —— 此时走第三条建议。

**抓到的商品会成为全局上下文** —— 之后生成图文、图片、视频都会带上它。做别的商品前记得点「清空商品上下文」。

### 图文生成

**两个按钮的区别**：
- 「① 生成纯文本」—— 只出文案，快，适合先看看方向对不对
- 「①+② 一步到位」—— 文案 + 3 张配图，慢一些

**平台选择影响的是人设和格式**，不只是字数。小红书和知乎出来的东西完全不同（一个是种草口吻 + 收藏引导，一个是论证结构 + 专业背书）。

**发布是跳转，不是直发**：点发布会打开对应平台的创作后台（小红书创作服务平台 / 公众号后台 / 头条号 / 知乎专栏 / 微博），登录后自己粘内容 —— 国内平台都没有开放的一键直发接口。

### 视频生成

**别跳过脚本检查环节**。生成脚本后可以「编辑脚本」改完再存，成片会按你改后的版本生成。改脚本比重出片便宜得多。

**两种成片**：
- 「生成单段视频」—— 一个镜头，快，适合试风格
- 「生成完整成片」—— 按分镜逐段生成再拼，慢，成品用这个

**时长 5–60 秒**。注意不同视频模型有各自的时长上限，超了系统会自动夹到合法范围。

**发布同样是跳转**：抖音创作者中心 / 快手创作者平台 / 视频号助手 / 小红书创作服务平台 / B站投稿页。

### 自由问答

不依赖任何前置上下文的通用问答。可以传参考图（模型会读图），可以打开**联网搜索**让它带上实时资料。支持多轮，对话历史保留在页面上，可一键清空。

### 文案创作 · Text Studio

**🎤 语音输入**：点「语音输入」直接说，实时显示识别结果。识别由**浏览器本地完成，音频不上传服务器**。需要 Chrome / Edge / Safari（Firefox 不支持）。

**「AI 优化提示词」值得先点一下** —— 把「写个猫砂盆的帖子」这种粗糙需求改写成结构化 prompt，出来的文案质量差别明显。

**输出区可以直接改**，改完再复制/导出。

### 图片创作

**参考图**：jpeg/png/webp，10MB 以内。有参考图时风格一致性明显更好。

**10 条内置提示词覆盖了国内自媒体全场景**：电商主图 / 美妆种草 / 型男穿搭 / 美食探店 / 旅游大片 / 数码评测 / 社媒广告 / 素人种草 / 大促海报 / 家居好物。不确定要什么时先点一条看看效果。

**图内文字是中文** —— 直接用中文描述即可。

### 视频创作

和「图片创作」同一套思路，10 条内置提示词：开箱测评 / 美食探店 / 美妆试色 / 型男穿搭 / 旅游 vlog / 数码实测 / 社媒广告 / 素人种草 / 直播预告 / 大促促销。

**两条路径**：直接出单条视频，或先出分镜脚本再逐段生成。分镜脚本可编辑，改完保存再出片。

### 棘手评论回复

**先选平台再贴评论**。四种语气差别很大：🎵 抖音短平快有梗、📕 小红书姐妹感有温度、🎬 视频号稳重偏私域、📰 公众号克制专业。

系统会**先给评论分类再决定回复策略**，所以差评、刁难、真实咨询会得到不同处理方式。

### 提示词配置

**改提示词是调整输出风格最有效的手段**，比在输入框里反复加要求管用。

- 按模块筛（7 个分类）或按名称搜
- 17 条全部是中文提示词，覆盖 5 个图文平台 + 5 个视频平台 + 图片/视频创作 + 评论运营 + 爆款拆解
- 改错了点「🔄 恢复默认」
- 你的改动只影响你自己

### 大模型配置

**当前 5 个模型可用、7 个禁用**。禁用原因直接写在模型名里（订阅已过期 / 额度已用尽 / 套餐未开通 / 账号欠费 / 端点已失效 / 厂商超时 / 账号余额不足）。

**禁用的模型不会出现在任何下拉里** —— 你在各模块选不到它们，这是刻意的：避免选了才发现报错。

**给某个模块换模型**：进对应页面（如「图文生成」），页面上的模型下拉直接切。点「设为默认」才会记住，否则只对本次生效。

**添加自定义模型**：填完 Base URL 和 API Key 后**先点「🔌 测试连接」**，通了再保存。

> 厂商恢复服务后，把状态从「禁用」改成「启用」就能用，不需要改代码。

### 大模型选购

想自己接一家厂商时看这页。13 家按「免费 / 费用低 / 费用中 / 费用高」排好，每家都给了购买入口和 API 文档链接。免费档两家：Agnes AI（新加坡）和硅基流动。

### 自媒体资产

**图片和视频是真的存在服务器上的**，不是只存了厂商链接 —— 厂商链接过期后资产还在。

按标题或内容全文搜索。6 个分类 Tab 切换。

### 用户中心

**修改密码后所有设备都要重新登录**（包括当前这台）。这是刻意设计：改密码通常是因为怀疑泄露。

## 四、进度会自动保存

**不用手动保存**。你填的内容在这些时机自动存到服务器：

- 打字停下 **2 秒**后
- 每 **30 秒**一次
- 关闭或刷新页面时

**保存的内容**：各页面输入框的文字、短视频脚本、分镜脚本、商品上下文（含你改过的核对区）、当前文章（标题+正文+配图）、平台和搜索源的选择。

**换设备登录进度也在** —— 存的是服务器，不是浏览器。

**上限 512KB**。超了会优先丢掉文章正文（保留标题），保证其他状态存得下。

> 「设为默认」的模型选择不走这套机制，单独持久化，所以刷新后不会被打回。

## 五、管理员专属功能

管理员账号（`role=admin`）多三个页面。普通用户**看不到也访问不到**（导航项和页面区块都被隐藏，手动滚动或改锚点也进不去）。

### 用户管理

- 看全部用户：ID / 用户名 / 角色 / 资产数 / 注册时间
- **重置任意用户密码** —— 重置后该用户所有登录态失效
- **删除普通用户** —— 连带清空其全部数据和媒体文件，不可恢复
- **管理员账号不可删除**，自己也删不掉

> 注意：管理员之间没有隔离，一个管理员可以重置另一个管理员的密码。

### 访客IP统计

访客 IP、地域、访问次数。定时自动刷新，可一键清空。

### 账号管理

绑定各平台自媒体账号（抖音 / 小红书 / 快手 / 微信视频号 / 微信公众号 / 今日头条 / B站）。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| **登录后一直跳回登录页** | 服务端 `GS_COOKIE_SECURE=1` 但你用 http 访问 → 浏览器静默丢 cookie。找管理员改成 0，或改用 https |
| **文案生成全部报鉴权错** | 服务端 `ARK_PLAN_API_KEY` 没配。注意它和 `ARK_API_KEY` 是**两把不同的 key**：前者走文本，后者走出图。只配了后者会出现"能出图但写不了文案" |
| **图片生成失败/破图** | 图片类模型目前只有「火山方舟 Seedream 4.0」可用。若它也失败，多半是 `ARK_API_KEY` 余额用尽 —— 页面会显示厂商返回的原始错误 |
| **视频模型选不到我想要的** | 7 个模型当前禁用（原因写在模型名里）。视频类只有「Agnes Video V2.0」和「Seedance 2 Mini」可用 |
| **视频生成一直转圈 / 提示"排队中"** | Agnes 厂商队列繁忙时任务会在排队状态停留数分钟，页面会明确告诉你「不是参数问题」。别去反复改时长和画幅 —— 等一两分钟重试，或切到「Seedance 2 Mini」 |
| **热点发现返回结果很少** | 换更具体的中文关键词，或切到另一个搜索源试试。两个源的召回特点不同 |
| **商品抓取一直失败** | 大平台（淘宝/京东/拼多多/抖音小店）反爬强，服务器直抓拿不到商品页。先用页面上的内置样例确认功能正常，实际商品手工把信息粘进核对区，效果一样 |
| **语音输入按钮点了没反应** | 换 Chrome / Edge / Safari。Firefox 不支持浏览器语音识别 |
| **提示词改坏了** | 提示词配置页点「🔄 恢复默认」 |
| **视频生成的文章下拉里有一堆看不懂的旧标题** | 那是改版前留在数据库里的历史资产，不影响功能。要清干净就在「自媒体资产」页删掉它们 |
| **换电脑登录，进度没了** | 检查是不是登录了不同账号。工作区按用户隔离，存在服务器上 |
| **忘记密码** | 找管理员在「用户管理」重置 |
| **页面样式全乱** | Tailwind CDN 加载不出来 —— 检查服务器/浏览器能不能访问 CDN |

## 七、使用建议

**先改提示词，再调输入。** 输出风格不对时，改「提示词配置」里的系统提示词比在输入框里反复加要求有效得多，而且一改永久生效。

**选品看「差评集中在」。** 好评说明市场存在，差评说明机会在哪。这一列是整张表最值钱的信息。

**商品抓取后一定看核对区。** 五秒钟的检查能省掉后面所有生成的返工。

**视频先出单段试风格，再出完整成片。** 成片贵且慢，风格不对时单段试错成本低得多。

**脚本改完再出片。** 改文字几乎免费，重新出片不是。

**内置提示词 chip 是起点不是终点。** 20 条内置提示词（图片 10 + 视频 10）覆盖国内自媒体全场景，先点一条看效果，再在它基础上改。
