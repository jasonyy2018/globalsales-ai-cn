# 自媒体AI运营平台 · 功能清单

> 国内自媒体 AI 运营平台。单文件前端 `index.html`（14,413 行 / 869 KB SPA，无构建步骤）+ 纯标准库后端 `server.py`（3,494 行，零 pip 依赖）+ SQLite。
>
> 本文按**左侧导航的真实顺序**罗列，与代码一一对应。带 🔒 的是管理员专属。

---

## 一、总览

侧栏共 **24 个功能页**，被 6 条分隔线切成 7 组：

| 组 | 页面 | 定位 |
|---|---|---|
| 1 · 选品 | 选品 | 入口：先定卖什么 |
| 2 · 内容主链路 | 热点发现 → 商品情报抓取 → 图文生成 → 视频生成 → 自由问答 | 主流水线，前后有数据传递 |
| 3 · 创作工具 | 文案创作 / 图片创作 / 视频创作 / 热门评论衍生 / 棘手评论回复 | 单点工具，可独立使用 |
| 4 · 资产与账号 | 账号管理 🔒 / 自媒体资产 / 访客IP统计 🔒 | 产出沉淀与运维 |
| 5 · 参考资料 | 主流电商平台 / 主流社媒平台 / 国内营销节日 / 电商运营指标 | 静态知识库，只读 |
| 6 · 配置 | 提示词配置 / 大模型配置 / 大模型选购 | 调参 |
| 7 · 帮助与账户 | 操作演示 / 用户中心 / 用户管理 🔒 | 账号与上手 |

**单语界面**：纯中文，无英文切换（侧栏底部语言按钮已失效，保留仅为兼容历史调用点）。

**核心设计原则**：所有对外发布的文案、图片内文字、视频脚本**面向国内自媒体平台**，中文全流程，无英文/海外定位。

## 二、逐页功能

### 1. 选品 `AI`

关键词 → 输出 11 列候选品表格。

- **筛选前置项**：价格带（自由文本框，无默认范围，placeholder=「不限」）、最低好评率（默认 85%）
- **10 个内置关键词** chip：智能宠物用品、人体工学家居、户外露营装备、家用健身器材、厨房小家电、美容个护仪器、智能家居、3C 数码配件、母婴用品、车载用品
- **输出列**：商品名称 / 平台详情页 / 近一个月销量 / 客单价 / 特点备注 / 好评率 / 差评率 / 好评集中在 / 差评集中在 / 购买人群·年龄段
- **复制表格**：带边框的富文本表格（可直接粘进 Excel / Word / 飞书），同时挂 `text/html` 与 `text/plain`
- **诚实性约束**：抓不到的字段标 `N/A`，不让模型编数字。页面常驻数据可信度提示条

### 2. 热点发现 `实时`

双引擎热点搜索 + 分类过滤。

- **两个搜索源**：🔍 全网搜索（Bing/百度）/ 📰 资讯聚合（AI 情报）
- 切换搜索源时，10 个内置关键词也跟着换一套
- **7 个分类**：全部 / AI 技术 / 短视频 / 内容创作 / 平台动态 / 行业趋势 / 变现运营
- **4 个统计卡**：今日热点数、最高热度值、匹配我的关注、已生成文章
- 每张热点卡可直接「生成图文」/「生成视频脚本」，一键带着上下文跳到对应页

### 3. 商品情报抓取 `URL`

粘贴商品链接 → 结构化商品卡，作为后续所有生成的上下文。

- 支持 **通用独立站 / 有赞 / 微盟等国内商城（ld+json / Shopify 结构）**
- 抓取：标题、价格、图片、要点、评分等
- 内置 **8 个实测可抓的当当商品页**样例，一键抓取
- **副文本核对区**：contenteditable 富文本，抓不准可手工改，改动会被后续生成采纳
- **反爬识别**：命中验证码页/拦截页时明确告知并给出三条建议（重试 / 换规范详情页链接 / 手工粘副文本），不把验证码页的标题当商品名
- 抓到的商品会成为 `currentProductContext`，图文/视频/图片生成都会读它；可「清空商品上下文」

### 4. 图文生成

主题 → 平台化中文软文 + 3 张配图。

- **5 个平台人设**：小红书 / 微信公众号 / 今日头条 / 知乎 / 微博
- **两种生成模式**：
  - 「① 生成纯文本」——只出文案，快
  - 「①+② 一步到位」——文案 + 3 张配图
- 配图简报由文章内容派生，保证图文相关
- 生成结果自动存入自媒体资产

### 5. 视频生成

文章/主题 → 分镜脚本 → 成片。

- 可从「已生成文章」下拉直接选素材
- **5 个平台**：抖音 / 快手 / 微信视频号 / 小红书 / B站
- 时长 5–60 秒可调
- **脚本环节完整闭环**：复制 / 翻译成中文 / 导出 / **可编辑**（改完存回，后续生成用改后的）
- **两种成片**：「生成单段视频」（一个镜头）/「生成完整成片」（按分镜逐段生成）
- 出片后可导出，或跳转平台后台上传

### 6. 自由问答

通用 AI 问答工作台，不依赖前置上下文。

- 文本输入 + 语音输入（浏览器原生语音识别，Chrome/Edge/Safari）
- 参考图上传（jpeg/png/webp，≤10MB），支持多轮对话
- 支持联网搜索（`/api/web_search`）
- 对话历史保留，可清空

### 7. 文案创作 · Text Studio

通用中文文案工作台。

- **4 种文案类型**：软文推广 / 视频脚本 / 短平快帖子 / 私域推文
- **10 个投放位**：抖音 / 快手 / 微信视频号 / 小红书 / B站 / 微信公众号 / 今日头条 / 知乎 / 微博 / 淘宝·天猫详情页
- **🎤 语音输入**：浏览器原生语音识别，实时预览。音频不经过服务器（需 Chrome/Edge/Safari）
- **AI 优化提示词**：把粗糙需求改写成结构化 prompt
- 10 条内置提示词 chip
- 输出区可直接编辑，支持复制全文 / 翻译成中文 / 导出 .txt / 重新生成

### 8. 图片创作

文本/参考图 → 商用图。

- **参考图上传**：jpeg/png/webp，≤10MB，可移除
- **10 条内置提示词**（覆盖国内电商全场景）：🖼️ 电商主图 / 💄 美妆种草 / 👔 型男穿搭 / 🍜 美食探店 / 🏔️ 旅游大片 / 📱 数码评测 / 📣 社媒广告 / 👤 素人种草 / 🎉 大促海报 / 🏠 家居好物
- 一次出 1–6 张（默认 3）
- **图内文字强制中文**
- AI 优化提示词 + 翻译成中文
- 破图占位与失败提示常驻，不静默失败

### 9. 视频创作

独立的视频生成工作台（与「视频生成」的区别：这里不依赖文章）。

- 支持参考图
- **10 条内置提示词**：📦 开箱测评 / 🍜 美食探店 / 💄 美妆试色 / 👔 型男穿搭 / 🏔️ 旅游 vlog / 📱 数码实测 / 📣 社媒广告 / 👤 素人种草 / 🔴 直播预告 / 🎉 大促促销
- **两条路径**：直接生成单条视频 / 先生成分镜脚本再逐段生成
- 分镜脚本**可编辑**，改完保存再出片
- AI 优化提示词 + 翻译成中文

### 10. 热门评论衍生

一条爆款评论 → 多条衍生内容。中文输入，中文输出，原创内容方向。

### 11. 棘手评论回复

难处理的评论（差评、刁难、公关危机）→ 得体中文回复。

- **4 种平台语气**：🎵 抖音 · 短平快有梗 / 📕 小红书 · 姐妹感有温度 / 🎬 视频号 · 稳重偏私域 / 📰 公众号 · 克制专业
- 先分类再回复（`classifyAndReply`），不同类型的棘手评论走不同策略
- 输入框内置 3 个示例棘手评论

### 12. 账号管理 🔒

绑定多平台自媒体账号：抖音 / 小红书 / 快手 / 微信视频号 / 微信公众号 / 今日头条 / B站。侧栏带动态计数徽标。

### 13. 自媒体资产

所有产出的统一归档。

- **6 个分类 Tab**：📋 全部 / 📝 图文文章 / 🖼️ 图片 / 🎬 短视频脚本 / 🎥 短视频 / 🔥 爆款拆解
- 按标题/内容**全文搜索**
- 图片和视频**落盘到服务器**（`data/users/<uid>/`），不是只存 URL，厂商链接过期也还在
- 视频内置播放器，文章弹窗查看
- 侧栏常显资产计数

### 14. 访客IP统计 🔒

访客 IP、地域、访问次数统计表，定时自动刷新，可一键清空。

## 三、跨页面能力

### 工作区自动保存

关掉浏览器、刷新、换机器登录，进度都还在。

**保存内容**：8 个输入框的文字、短视频脚本、分镜脚本、商品上下文（含手工改过的核对区）、当前文章（标题+正文+3 张配图）、平台选择、搜索源选择。

**保存时机**：
- 打字停下 **2 秒**后自动存
- 每 **30 秒**定时存一次
- 关闭/刷新页面时存一次

**上限 512KB**，超了优先丢文章正文（保留标题），而不是整块丢弃。

> 模型选择**不走工作区**，由 `module_defaults` 独立持久化 —— 否则「设为默认」会被工作区快照打回。

### 数据隔离

每个用户只能看到自己的资产、提示词、模型配置、工作区。所有查询都带 `WHERE user_id = ?`，没有"先查出来再判断属主"的时间窗。

### 内置模型密钥保护

厂商 API Key **只存在服务器**，从不下发到浏览器。三道闸：
1. `GET /api/data/models` 读时强制把内置模型的 `apiKey` 置空
2. `POST /api/data/models` 写时拒绝把平台密钥落库
3. 启动时一次性清库（含"把内置端点手动加成自定义模型"的绕过写法）

否则任何注册用户 F12 打一次接口就能抄走全部厂商密钥。

### 单语界面

纯中文，无英文词典。`window.I18N` 中只有 `zh` 字典，`currentLang === 'en'` 的 30 处分支为死代码。`data-i18n` 属性 334 处，`applyI18n()` 运行时以 HTML 中的中文 fallback 为准。

## 四、当前已知限制

写在这里是为了让使用者不会误判，而不是遗漏。

| 限制 | 说明 |
|---|---|
| **7 个模型不可用** | 见上表，原因各异（订阅过期/额度/欠费/端点失效/厂商超时/账号余额不足）。图片类目前只有 Seedream 4.0 一个可用，视频类只有 2 个 |
| **图文生成的中文人设已改为国内平台** | 小红书 / 微信公众号 / 今日头条 / 知乎 / 微博 |
| **「爆款拆解」无独立入口** | 提示词和资产分类都有，但没有对应的生成页面 |
| **语音输入依赖浏览器** | 仅 Chrome / Edge / Safari；Firefox 无此能力 |
| **管理员之间无隔离** | 管理员可以重置其他管理员的密码（但删不掉） |
| **滚动高亮漏一项** | 滚到「用户管理」时侧栏高亮停在「用户中心」（不影响功能） |
| **视频生成下拉显示旧资产标题** | 预转换前的英文资产标题仍存在于数据库中，不影响功能 |
