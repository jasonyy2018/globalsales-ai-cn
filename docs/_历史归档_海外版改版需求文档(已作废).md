# 海外社媒AI运营平台 — 改版需求文档

> **文档版本**：v1.0  
> **编制日期**：2026-07-24  
> **当前系统**：自媒体AI运营平台（国内版，基于 Python + HTML/CSS/JS 单页应用架构）  
> **改版目标**：面向海外社交媒体运营的 AI 赋能平台  

---

## 第一部分：当前系统架构分析

### 1.1 技术架构总览

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| **前端** | 原生 HTML + CSS + Tailwind CDN + Vanilla JS | 单页应用（SPA），所有功能在 `index.html` 中 |
| **后端** | Python 3（标准库 `http.server`） | 代理服务器 + 静态文件服务器，端口 8766 |
| **数据持久化** | 浏览器 `localStorage` | 所有生成内容、账号配置、模型配置均存于本地 |
| **AI引擎集成** | 反向代理模式 | 前端直接调用 `/api/*` 后端代理转发至各 AI 厂商 API |

### 1.2 现有功能模块

| 模块 | 功能 | 支持的AI模型 |
|------|------|-------------|
| **热点发现** | 实时抓取 Bing/百度搜索结果，展示热点话题列表 | 无（纯爬虫 + 热度模拟） |
| **图文生成** | 按平台人设 Prompt 生成图文文章（HTML格式） | 火山方舟 / MiniMax Claude |
| **短视频生成** | 生成短视频脚本 + 调用视频模型生成视频 | Seedance 2 Mini / Agnes AI / MiniMax / 腾讯混元 |
| **图片创作** | 上传参考图 + 文字描述生成图片 | Agnes AI / MiniMax |
| **视频创作** | 独立视频生成入口，支持参考图 + 提示词 | Seedance 2 Mini / Agnes AI / 腾讯混元 / MiniMax |
| **热门评论衍生** | 基于一条评论衍生多条相似评论 | 火山方舟 / MiniMax |
| **棘手评论回复** | 意图分析 + 自动生成回复文案 | 火山方舟 / MiniMax |
| **账号管理** | 管理国内自媒体账号绑定（模拟） | 仅 UI 模拟，无实际API接入 |
| **自媒体资产库** | 本地存储所有生成内容（文章、图片、视频） | 浏览器 localStorage |
| **访客IP统计** | 记录访客 IP 和访问统计 | 后端记录 |
| **提示词配置** | 在线编辑各模块的 System Prompt | 持久化到 localStorage + 同步到 index.html |
| **大模型配置** | 动态增删改模型节点（名称、Base URL、协议、API Key） | 持久化到 localStorage + 同步到 index.html 和 server.py |

### 1.3 现有AI模型配置

系统已预置 9 个模型节点，覆盖文本、图片、视频三类能力：

| 模型ID | 名称 | 协议 | 能力 |
|--------|------|------|------|
| `ark-text` | 火山方舟 Coding Plan | OpenAI 兼容协议 | 文本生成（文案/脚本） |
| `minimax-text` | MiniMax Claude 2.7 | Anthropic Messages API | 文本生成 |
| `minimax-image` | MiniMax Image-01 | MiniMax 原生协议 | 图片生成 |
| `minimax-video` | MiniMax T2V-01 | MiniMax 原生协议 | 视频生成 |
| `hunyuan-image` | 腾讯混元 Image | 腾讯混元 API | 图片生成 |
| `hunyuan-video` | 腾讯混元 hy-video-1.5 | 腾讯混元 API | 视频生成 |
| `agnes-image` | Agnes AI Image 2.1 Flash | OpenAI 兼容协议 | 图片生成 |
| `agnes-video` | Agnes AI Video V2.0 | OpenAI 兼容协议 | 视频生成 |
| `seedance-mini-video` | Seedance 2 Mini | AggregateAPI 异步任务 | 视频生成 |

### 1.4 系统架构优势与局限

**优势**：
- 零外部依赖（仅 Python 标准库），部署极简
- 前端单页应用，响应式设计，操作流畅
- 模型管理动态化，支持在线增删改
- 热点搜索基于真实搜索引擎抓取，非伪造数据

**局限**：
- 无后端数据库，数据仅存 localStorage，跨设备无法同步
- 无用户认证系统，多用户不可用
- 账号管理为 UI 模拟，无实际第三方平台 API 接入
- 所有内容为中文，无国际化支持
- 热点搜索仅覆盖国内搜索引擎（Bing/百度）

## 第二部分：改版需求详细分析

### 需求 1：AI 模型后台管理 —— 动态配置 AI 模型

#### 需求描述
后台支持动态配置 AI 模型，可增删改模型节点，包括模型名称、Base URL、协议类型等参数。

#### 可行性分析
| 维度 | 评估 |
|------|------|
| **当前支持** | ✅ **完全支持**。已有完整的 `大模型配置` 模块，支持在线增删改模型节点 |
| **模型属性** | 当前模型节点包含：`id`、`name`、`provider`、`baseUrl`、`protocol`、`type`、`status`、`apiKey`，满足需求 |
| **持久化机制** | 1. 前端存 `localStorage` 2. 同步写回 `index.html` 和 `server.py` 的 `syncConfig` API |
| **协议支持** | 当前支持：OpenAI 兼容协议、Anthropic Messages API、MiniMax 原生协议、腾讯混元 API、AggregateAPI 异步任务 |
| **不足** | 需新增 Base URL 协议类型选择器（HTTP/HTTPS/Socket），当前仅支持预设协议 |

#### 实施建议
- ✅ 当前系统已具备此能力，仅需将 UI 文本和默认协议选项从中文适配为英文/多语言
- ⚠️ 如果后端需要新增协议类型，需在 `server.py` 的 `API_ROUTES` 路由表中增加对应路由配置逻辑
- 建议新增字段：`model`（模型名称，如 `gpt-4`）、`maxTokens`、`temperature` 等参数

### 需求 2：海外社媒一键发布 —— TikTok/YouTube/Instagram/Pinterest/Facebook/Twitter

#### 需求描述
针对 TikTok、YouTube、Instagram、Pinterest、Facebook、Twitter 等平台，通过开放 API 实现一键发布。

#### 可行性分析

##### 各平台 API 发布可行性

| 平台 | 官方 API 发布 | 认证方式 | 难度 | 合规风险 |
|------|-------------|---------|------|---------|
| **YouTube** | ✅ YouTube Data API v3 | OAuth 2.0 | 中 | 低 — 官方支持 |
| **Facebook / Instagram** | ✅ Facebook Graph API + Instagram Content Publishing API | OAuth 2.0 + Page/User Token | 中 | 低 — 官方支持 |
| **Twitter (X)** | ✅ Twitter API v2（需 Basic/Pro 付费订阅） | OAuth 2.0 / OAuth 1.0a | 中 | 中 — 免费额度极少 |
| **Pinterest** | ✅ Pinterest API | OAuth 2.0 | 中 | 低 — 官方支持 |
| **TikTok** | ✅ TikTok Content Posting API（需企业认证） | OAuth 2.0 + Access Token | 高 | 中 — 需申请开发者资质 |
| **LinkedIn** | ✅ LinkedIn Marketing API / Share API | OAuth 2.0 + 会员认证 | 中 | 低 — 官方支持 |

##### 爬虫方式的合规风险

| 结论 | 说明 |
|------|------|
| ❌ **强烈不建议使用爬虫发布** | 绝大多数平台禁止模拟登录后自动发布内容，违反 ToS 会导致账号封禁 |
| ⚠️ **法律风险** | 在美国《Computer Fraud and Abuse Act》(CFAA) 和欧盟 GDPR 框架下，未经授权的自动化访问可能构成违法 |
| ✅ **推荐方案** | 仅使用官方公开 API，通过 OAuth 2.0 授权流程进行内容发布 |

##### 技术实施建议

**推荐方案：统一发布网关**

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  平台前端       │────▶│  发布网关服务     │────▶│ YouTube API     │
│  (内容编辑后)   │     │  (Python 后端)    │     │ Facebook API    │
│                 │     │                   │     │ TikTok API      │
│                 │     │                   │     │ Twitter API     │
│                 │     │                   │     │ Pinterest API   │
│                 │     │                   │     │ LinkedIn API    │
└─────────────────┘     └──────────────────┘     └─────────────────┘
```

**实现要点**：
1. 后端新增 OAuth 2.0 授权流程处理模块
2. 对每个平台封装独立的发布适配器（Adapter Pattern）
3. 内容格式自动转换（如 YouTube 需要视频文件 + 标题 + 描述；Twitter 需要短文本 + 图片）
4. 发布状态轮询 + 失败重试队列

**预计工作量**：每个平台适配器约 2-3 天，总计约 2-3 周开发时间

### 需求 3：各平台内容风格提示词 —— 海外主流社媒平台专属提示词

#### 需求描述
为海外主流社媒平台提供专属的内容生成提示词（图文文章、视频脚本等），并分类视频为主 vs 图文/软文为主的平台。

#### 平台分类

##### 视频内容为主平台

| 平台 | 核心内容形式 | 内容特点 | 建议提示词方向 |
|------|------------|---------|--------------|
| **TikTok** | 15-60秒短视频 | 快节奏、强钩子、音乐驱动、病毒式传播 | 前3秒钩子、热点音乐、挑战赛趋势、口语化旁白 |
| **YouTube** | 长视频（8-20分钟为主） | 深度内容、教程、Vlog、开箱评测 | 开场Hook、章节结构、CTA引导、SEO关键词 |
| **Instagram Reels** | 15-90秒短视频 | 审美驱动、生活方式、品牌调性 | 视觉冲击、品牌色彩、快节奏剪辑、字幕处理 |
| **Facebook Watch** | 中长视频（3-10分钟） | 社交分享、故事性、社区讨论 | 话题性、情感共鸣、社区互动引导 |

##### 图文/软文内容为主平台

| 平台 | 核心内容形式 | 内容特点 | 建议提示词方向 |
|------|------------|---------|--------------|
| **Instagram Feed** | 图文帖（1-10张图） | 高审美、生活方式、品牌调性 | 封面设计、文案短小精悍、标签策略、CTA |
| **Pinterest** | 图钉（Pin）+ 图文 | 种草、灵感发现、教程分享 | 长图设计、标题SEO、分类标签、跳转链接 |
| **Twitter (X)** | 短文本（280字符 / X Premium 25K） | 实时、观点、新闻、Thread | 短句爆点、Thread结构、话题标签、引用回复 |
| **LinkedIn** | 长文帖 + 图文 | 专业、行业洞察、B2B、职业发展 | 数据驱动、专业人设、行业案例、互动引导 |
| **Facebook Feed** | 图文帖 + 链接分享 | 社交分享、社区互动、品牌故事 | 故事化叙事、情感共鸣、互动问答、投票 |

##### 混合内容平台

| 平台 | 视频占比 | 图文占比 | 策略建议 |
|------|---------|---------|---------|
| **Instagram** | ~40% (Reels) | ~60% (Feed + Story) | 两者兼顾，Reels 用于曝光，Feed 用于品牌沉淀 |
| **Facebook** | ~30% | ~70% | 视频用于互动，图文用于信息传递 |

#### 现有提示词 vs 海外平台提示词

当前系统已为国内平台配置了 14 个提示词（热点、图文、视频、图片、评论等），需要为海外平台新增对应提示词：

| 模块 | 需新增的海外平台提示词 |
|------|---------------------|
| **图文生成** | TikTok Caption Prompt、Instagram Caption Prompt、LinkedIn Article Prompt、Twitter Thread Prompt、Pinterest Pin Description Prompt、Facebook Post Prompt |
| **短视频脚本** | TikTok Script Prompt、YouTube Script Prompt、Instagram Reels Script Prompt、Facebook Short Video Script Prompt |
| **图片创作** | Instagram Feed Visual Prompt、Pinterest Pin Visual Prompt、YouTube Thumbnail Prompt |
| **评论运营** | 海外平台评论风格（英文回复语气、emoji使用规范、平台文化差异） |

#### 实施建议
- 海外平台提示词需以英文撰写，并包含平台特有文化元素
- 提示词需由英语母语者或资深海外运营人员审核
- 在提示词配置模块中新增 `language` 字段，区分中英文提示词

### 需求 4：数字人视频生成

#### 需求描述
生成短视频时，使用数字人形象出镜并自动配音、匹配素材。

#### 可行性分析

##### 主流数字人方案对比

| 方案 | 能力 | 接入方式 | 费用 | 中文支持 | 英文支持 |
|------|------|---------|------|---------|---------|
| **HeyGen** | 数字人出镜 + 口播 + 多语言 | API | $24/月起 | ✅ | ✅ |
| **Synthesia** | AI虚拟主播 + 多语言 | API | $89/月起 | ❌ | ✅ |
| **D-ID** | 数字人 + 面部动画 + 语音 | API | $5.99/月起 | ✅ | ✅ |
| **ElevenLabs** | 语音克隆 + 多语言TTS | API | $5/月起 | ✅ | ✅（最优质） |
| **Azure TTS** | 多语言TTS + 情感语音 | API | 按量付费 | ✅ | ✅ |
| **OpenAI TTS** | 自然语音合成 | API | 按量付费 | ❌ | ✅ |
| **SadTalker** | 开源数字人（图片+音频驱动） | 本地部署 | 免费 | ✅ | ✅ |
| **MuseTalk** | 开源实时数字人 | 本地部署 | 免费 | ✅ | ✅ |

##### 推荐集成架构

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  用户选择数字人   │────▶│  后端编排服务     │────▶│ HeyGen API       │
│  形象 + 文案     │     │  (Python)         │     │  (数字人生成)    │
│                 │     │                   │     │                 │
│                 │     │  或：              │────▶│ ElevenLabs TTS   │
│                 │     │  本地开源方案      │     │  + SadTalker     │
│                 │     │                   │     │  (本地部署)      │
└─────────────────┘     └──────────────────┘     └─────────────────┘
```

##### 实施建议

**推荐方案（按优先级）**：

1. **Phase 1 — 快速集成 HeyGen API**（1-2周）
   - 注册 HeyGen 开发者账号，获取 API Key
   - 后端新增 `/api/digital_human` 路由
   - 前端新增数字人形象选择界面
   - 输入文案 → 选择数字人形象 → 生成数字人视频

2. **Phase 2 — 本地开源方案**（2-3周）
   - 部署 SadTalker / MuseTalk 到本地服务器
   - 集成 ElevenLabs 或 Azure TTS 进行语音合成
   - 实现图片 + 音频 → 数字人视频的流程

3. **Phase 3 — 素材匹配**（1-2周）
   - 分析文案内容，自动匹配背景素材/画面
   - 数字人 + B-Roll 素材混合渲染

##### 接入系统方式

当前系统采用代理模式，数字人 API 可作为新路由加入 `server.py` 的 `API_ROUTES`：

```python
'/api/digital_human': {
    'url': 'https://api.heygen.com/v2/video/generate',
    'method': 'POST',
    'auth_type': 'bearer',
    'auth_key': HEYGEN_API_KEY,
    'extra_headers': {}
}
```

### 需求 6：海外热点搜索

#### 需求描述
从海外主流媒体搜索热点话题，支持按关键词检索（如搜索"智能猫砂"返回相关热点），便于围绕主营品牌撰写文章和短视频。

#### 可行性分析

| 维度 | 评估 |
|------|------|
| **当前能力** | 当前系统支持 Bing 新闻搜索 + 百度搜索，返回中文结果 |
| **海外扩展** | ✅ 可行。可扩展搜索源至 Google News、Reddit、Twitter Trends、YouTube Trends 等 |

### 需求 8：文章分步生成流程

#### 需求描述
1. 先生成纯文本文章（不插入图片）
2. 供人工审核和修改
3. 审核通过后提供按钮一键插入 3 张应景图片
4. 最终输出中英文两个版本
5. 发布的最终文章和视频以英文版为准

#### 可行性分析

| 维度 | 评估 |
|------|------|
| **纯文本生成** | ✅ 当前系统已生成纯 HTML 文章，但包含图片占位。需修改 Prompt 禁止插入图片 |
| **人工审核编辑** | ✅ 当前系统已有富文本编辑器（`editor-content` 可编辑区域） |
| **一键插入图片** | ✅ 可行。AI 分析文章内容，自动生成 3 张匹配图片提示词，调用图片生成 API |
| **中英文版本** | ✅ 见需求 5 |
| **英文版发布** | ✅ 见需求 5 |

#### 分步流程设计

```
Step 1: 输入主题 → 选择平台 → 点击"生成文章"
        │
        ▼
Step 2: AI 生成纯文本文章（无图片）
        │ 显示在富文本编辑器中
        │ 标记为"草稿状态"
        │
        ▼
Step 3: 人工审核与修改
        │ 编辑器中直接修改文字
        │ 调整标题、段落、措辞
        │
        ▼
Step 4: 确认审核通过 → 点击"一键配图"
        │
        ▼
Step 5: AI 分析文章内容
        │ 自动生成 3 组图片提示词
        │ 调用图片 API 生成 3 张图片
        │ 自动插入文章对应位置
        │
        ▼
Step 6: 中英文版本切换查看
        │ 中文版本（编辑用）
        │ 英文版本（最终发布用）
        │
        ▼
Step 7: 发布 → 自动选择英文版本
        │ 图文文章 → 对应平台
        │ 视频 → 英文口播 + 英文字幕
```

#### 需求描述

| **图片抓取** | ✅ 可行。抓取商品主图、详情图 |
| **自动生成图文** | ✅ 可行。AI 基于商品信息生成推广文案 + 配图 |
| **自动生成短视频** | ✅ 可行。AI 生成脚本 + 视频模型生成 |

## 第五部分：风险评估与注意事项

### 5.1 合规风险

| 风险项 | 等级 | 说明 | 应对措施 |
|--------|------|------|---------|
| 爬虫抓取商品信息 | ⚠️ 中 | 可能违反电商平台 ToS | 优先使用官方 API；控制爬取频率 |
| 自动发布到社媒 | ⚠️ 中 | 需遵守各平台内容政策 | 仅用官方 API；内容审核机制 |
| 商品图片版权 | ⚠️ 中 | 抓取的商品图片可能受版权保护 | 仅用于内容生成参考；建议使用 AI 生成替换图片 |
| OAuth Token 安全 | ⚠️ 中 | 用户授权 Token 存储 | 加密存储；HTTPS 传输 |
| AI 生成内容真实性 | ⚠️ 低 | 商品描述需真实准确 | 人工审核环节；标注 AI 生成 |

### 5.2 技术风险

| 风险项 | 等级 | 说明 | 应对措施 |
|--------|------|------|---------|
| 海外 API 访问延迟 | 中 | 海外 API 在中国大陆访问可能不稳定 | 部署海外代理节点 |
| API 配额限制 | 中 | YouTube/Reddit 等有免费配额限制 | 多账号轮换；付费方案 |
| 反爬虫升级 | 低 | 电商平台反爬虫策略变化 | 监控机制；快速适配 |
| 平台 API 变更 | 低 | 各平台 API 版本更新 | 适配器模式；版本管理 |

### 5.3 成本预估

| 项目 | 月费用估算 | 说明 |
|------|-----------|------|
| AI 模型调用（文本生成） | $50-200 | 火山方舟 / MiniMax 等 |
| AI 图片生成 | $50-300 | 按量计费 |
| AI 视频生成 | $100-500 | 成本最高 |
